aria2 Download Forwarder

This extension can send your browser downloads to an aria2 server instead of saving them locally. It takes about a minute to set up.

1. Where is aria2?

aria2 must run with --enable-rpc (and --rpc-listen-all if it's on another machine). For a server other than localhost, the browser asks you to allow access to that host.

2. How should it behave?

If this is off, you can still right-click any link and choose Send link to aria2. You can set size and domain filters in the options.

3. Done

Open all options
